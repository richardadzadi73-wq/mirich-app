# 2-week beta plan
**Cohort:** 30–50 people across ≥3 countries, ≥10 on iPhone, ≥10 on Android, ≥5 on slow mobile data.
**Week 1:** install via link, 1:1 chat, groups, photos, voice notes, calls (Wi-Fi ↔ mobile), push with app closed, enable encryption. **Week 2:** channels, group calls, language switch, Premium test payment, account deletion.
**Metrics:** day-1/day-7 retention • messages/user/day • call success rate (connected ÷ attempted; target >90%) • push delivery delay • crash/error rate (`client_errors`) • p95 send latency.
**Feedback:** Settings → Send feedback (table `feedback`), plus a WhatsApp/Telegram group. **Exit criteria:** call success >90%, zero data-leak bugs, <1% error sessions, RLS tests green.
